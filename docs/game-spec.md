# 拳嵐（KENRAN）仕様書

C++/DxLib で作るオリジナルの2D対戦格闘ゲーム。キャラ・技名・見た目・ステージはすべて独自のもの。

## 遊び方の全体

| モード | 内容 | 対応 |
|---|---|---|
| CPU と対戦 | 1P 対 CPU、2本先取。CPU の強さは「よわい／ふつう／つよい」 | Windows・Android |
| 2人で対戦 | 1台の PC で 1P 対 2P | Windows のみ |
| トレーニング | 相手（ダミー）の動きを選んで練習。体力・ゲージは自動で回復 | Windows・Android |

画面の流れ：タイトル → モード選択 → キャラクター選択 → 対戦 → 結果（もう一度／キャラ選択／タイトル）。対戦中はポーズメニューから、コマンド表を見たり、キャラ選択やタイトルに戻ったりできる。

## 操作

攻撃は「弱・中・強」の3つと、「必殺ショートカット」ボタン。

| 機器 | 移動 | 弱 | 中 | 強 | 必殺 | ポーズ |
|---|---|---|---|---|---|---|
| キーボード 1P | W A S D | J | K | L | I | Enter |
| キーボード 2P | 矢印キー | テンキー1 / `,` | テンキー2 / `.` | テンキー3 / `/` | テンキー0 / 右Shift | テンキーEnter |
| ゲームパッド | 十字・左スティック | X | Y | B・RB | A・LB | START |
| スマホ | 左下のスティック | 弱ボタン | 中ボタン | 強ボタン | 必殺ボタン | 上の「II」 |

- CPU 戦とトレーニングでは、どの機器でも 1P を操作できる。2人対戦では、1P がキーボードの WASD 側と1台目のパッド、2P が矢印キー側と2台目のパッドを使う。
- メニュー：決定は弱・必殺・Enter、戻るは強・Esc。マウスのクリックやタップでも選べる。

## システム

| 項目 | 内容 |
|---|---|
| フレーム | ゲームは 1/60 秒（1フレーム）ずつ進む。技の速さはフレーム数で決める |
| ガード | 相手と反対の方向でガード。下段はしゃがみガード、ジャンプ攻撃は立ちガードでしか防げない |
| ダッシュ | 前2回で前ダッシュ、後ろ2回でバックステップ（出始め8フレーム無敵） |
| 投げ | 近くで 弱＋中。後ろを入れながらだと逆側へ投げる。つかまれてから9フレーム以内に 弱＋中 で投げ抜け |
| チェーン | 当たった（ガードされた）通常技は、より強い通常技で取り消せる（弱→弱、弱→中→強） |
| キャンセル | 通常技が当たった瞬間に必殺技、必殺技が当たった瞬間に超必殺技を出せる |
| 超必殺技 | ゲージ（最大1000）が満タンで使える。当てる・当てられる・ガードで増え、ラウンドをまたいで持ち越す |
| ショートカット | 必殺ボタン＋方向（中立：↓↘→の技、前：→↓↘の技、後ろ：↓↙←の技、下：超必殺技）。強さは中 |
| カウンター | 相手の技の出始めに当てると、ダメージ1.2倍・のけぞり+4フレーム |
| コンボ補正 | 3発目から10%ずつ下がる（最低30%、超必殺技は最低50%） |
| アーマー | 岩砕拳の出始めは1回だけ攻撃を受けても止まらない（超必殺技と投げには負ける） |
| 先行入力 | ボタンは5フレーム前まで受け付ける。ヒットストップ中の入力も有効 |
| 試合 | 1ラウンド99秒、2本先取。時間切れは体力の割合が多い方の勝ち |

## キャラクター

### カザネ（風を継ぐ拳士）
体力1000。動きが速く、飛び道具と無敵対空で間合いを支配するバランス型。

| コマンド | 技 | 内容 |
|---|---|---|
| ↓↘→＋攻撃 | 風刃 | 飛び道具。強いほど速い |
| →↓↘＋攻撃 | 昇旋脚 | 出始め無敵の対空。強は2段。外すと着地に大きな隙 |
| ↓↙←＋攻撃 | 疾走掌 | 踏み込み突き。強はダウンを奪う |
| ↓↘→↓↘→＋攻撃 | 嵐舞（超必殺） | 突進して7連撃。出始め無敵 |

### ガンテツ（砕けぬ岩鉄）
体力1150。遅いが一撃が重いパワー型。

| コマンド | 技 | 内容 |
|---|---|---|
| ↓↘→＋攻撃 | 岩砕拳 | アーマー付きの突進パンチ。強はダウンを奪う |
| →↓↘＋攻撃 | 鉄槌 | 出始め無敵の突き上げ（対空） |
| ↓↙←＋攻撃 | 地裂波 | 地面を走る下段の衝撃波。強いほど遠くまで届く |
| ↓↘→↓↘→＋攻撃 | 剛岩崩（超必殺） | 近くの相手をつかむ投げ。ガード不能。のけぞり中の相手もつかめる |

技の数値（発生・持続・硬直・ダメージ・判定など）は `src/common/CharacterData.cpp` にまとめてある。

## CPU

人と同じ「方向＋ボタン」の入力を作ってキャラを動かす。相手の動きは反応時間ぶん遅れて見える。

| 強さ | 反応 | ガード | 対空 | コンボ | 反撃 | 投げ抜け |
|---|---|---|---|---|---|---|
| よわい | 24F | 20% | 10% | 20% | 15% | 5% |
| ふつう | 15F | 55% | 45% | 65% | 50% | 30% |
| つよい | 8F | 85% | 80% | 95% | 85% | 60% |

## ソースの構成（src/common）

| ファイル | 役割 |
|---|---|
| `Game` / `GameLoop` | 60fps 固定の更新、画面の切り替え（フェード） |
| `Scene.h` / `MenuScenes` / `BattleScene` | 各画面（タイトル・モード・操作方法・キャラ選択・結果・対戦とポーズ） |
| `Battle` / `BattleDraw` | 試合の進行（判定・投げ・飛び道具・ラウンド）と描画（HUD・演出） |
| `Fighter` | キャラ1人の状態と動き、判定の位置 |
| `CharacterData` | キャラと技のデータ |
| `CpuBrain` | CPU の判断 |
| `Input` / `InputHistory` / `Pad` / `VirtualPad` | 入力機器の統合、コマンド判定、仮想パッド |
| `Pose` | 関節の位置で体を描く仕組みとポーズの一覧 |
| `Stage` | ステージの背景（夕焼けの河原・夜の採石場） |
| `Sound` | 効果音（起動時に波形を合成） |
| `Text` / `Ui` | 文字とメニューの部品 |

絵や音の素材ファイルは使っていない（すべてプログラムで描画・合成）。
