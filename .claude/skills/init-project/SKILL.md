# プロジェクト初期設定

CLAUDE.mdの作業ルールに従って進める。
ただし、次の「書式」に定めた点は、このスキル独自の書式を優先する。

## 書式

- 開始時に、最も最初に初期設定の手順を次の一覧で表示してから、最初の項目に進む。
  1. プロジェクト名
  2. プロジェクトの説明
  3. 初期設定の反映
- 以降の各返信、各項目の冒頭に、現在の項目と進捗を
  「プロジェクト名(1/3)」の形式で表示する。
- 各手順は、1回の返信につき1つずつ進める。
- 表示するのは、ユーザーへの指示・質問・確認だけとし、端的に書く。
- 実際に行う作業の内容や結果（ファイルの変更内容、コマンド、
  コミットなど）は表示しない。ただし、エラーで作業を進められない
  場合は、その旨だけを伝える。
- 回答・提案・判断に理由を添える必要はない
  （CLAUDE.mdの「理由を添える」ルールより優先する）。

## 手順

1. プロジェクト名：プロジェクト名を質問する。
2. プロジェクトの説明：プロジェクトの説明を質問する。
3. 初期設定の反映：これまでに入力されたプロジェクト名・説明と、
   下の「アプリID」の決め方で作ったAndroidのアプリIDをまとめて表示し、
   実行内容を「初期設定を反映する」として実行許可を求める。
   「実行」指示を受けたら、次をすべて行う。
   - CLAUDE.md の「プロジェクト情報」欄にプロジェクト名・説明を記入
     （開発環境は「C++/DxLib」のまま）
   - README.md の1行目を「# プロジェクト名」に、その下の
     「このリポジトリはテンプレートから作成されました。」と
     「Claude Code で `/init-project` を実行して初期化してください。」の
     2行をプロジェクトの説明に書き換える（それより下のビルドの説明は残す）
   - 下の「プロジェクト名の反映」をすべて行う
   - このスキル（.claude/skills/init-project）を削除
   - コミット（メッセージ「プロジェクトの初期設定」）とpush
   - pushしたブランチからmainへのプルリクエスト（PR）を作成し、マージする
   すべて完了したら、初期設定が完了したことだけを伝える。
   PRの作成またはマージができなかった場合は、mainへ反映するには
   PRの作成とマージが必要なことを伝え、その説明の末尾にURLを表示する。
   URLは、PRを作成済みならそのPRのURL、未作成ならPR作成画面のURL
   （https://github.com/<ユーザー名>/<リポジトリ名>/compare/main...<ブランチ名>）
   とする。そのうえで「マージ手順を表示しますか？」と質問し、
   次の選択肢を示す。
   1. 不要
   2. 必要
   2が選ばれた場合は、URLで開いた画面から、ユーザーがブラウザで
   マージするまでの手順を表示する。

## プロジェクト名の反映

テンプレートでは仮の名前「Game」を使っている。次の箇所をプロジェクト名に置き換える。

- ファイル名に使う名前：プロジェクト名から、Windowsのファイル名に使えない文字
  （`\ / : * ? " < > |`）を `_` に置き換えたもの。以下「ファイル名」と呼ぶ。
- `windows/Game.sln` と `windows/Game.vcxproj` を、`git mv` で
  `windows/<ファイル名>.sln` と `windows/<ファイル名>.vcxproj` に名前を変える。
  - .sln の中の `Project(...) = "Game", "Game.vcxproj", ...` の2か所を
    `"<ファイル名>", "<ファイル名>.vcxproj"` に変える。
  - .vcxproj の中の `<RootNamespace>Game</RootNamespace>` を
    `<RootNamespace><ファイル名></RootNamespace>` に変える。
  - どちらのファイルも、文字コード（BOM付きUTF-8）と改行（CRLF）を変えない。
  - exe の名前は .vcxproj のファイル名で決まる。GitHub Actions（build.yml）は
    windows フォルダの .sln と .vcxproj を自動で探すので、書き換えない。
- `src/common/Config.h` の `WindowTitle` の `"Game"` をプロジェクト名にする
  （C++の文字列として `\` と `"` は `\\` と `\"` にする）。
- `android/app/src/main/res/values/strings.xml` の `app_name` の `Game` を
  プロジェクト名にする（`&` `<` は `&amp;` `&lt;` に、`'` `"` は `\'` `\"` にする）。
- `android/settings.gradle` の `rootProject.name = 'Game'` をプロジェクト名にする
  （`\` と `'` は `\\` と `\'` にする）。
- `android/app/build.gradle` の `namespace` と `applicationId`
  （どちらも `com.telog1204.claudedxlibtemplate`）を、下の「アプリID」にする。

## アプリID

Androidのアプリ（パッケージ）IDは `com.<オーナー名>.<リポジトリ名>` とし、
オーナー名とリポジトリ名は git のリモート（origin）のURLから取る。
それぞれ次のように変換する。

- 英字を小文字にし、英小文字と数字以外の文字（`-` `_` `.` など）を取り除く。
- 先頭が数字のとき、または取り除いた結果が空のときは、先頭に `app` を付ける。
- Javaの予約語（`class` `new` `int` など）と同じになったときは、末尾に `app` を付ける。

例：リポジトリ `telog1204/my-game` → `com.telog1204.mygame`
